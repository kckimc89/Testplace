# 세계 명소대백과 · 41개국 새 출발 V1.1

독립 Testplace 설치용 전체 파일입니다. 41개국/798개 명소 자료를 유지하며 기존 15개국 원본 저장소는 변경하지 않습니다. 사진 이관은 하지 않습니다.

* 별도 최상위 「사진 여행」에서 기존 위키미디어 사진 검색과 후보 선택 기능 사용
* 기본사진첩은 검색 기능과 분리, 순서/대표사진/슬라이드쇼 관리 유지
* 새 저장 사진은 긴 변 800px, WebP 품질 40으로 변환 후 IndexedDB 보관. 명소별 30장 제한
* 부모모드에서 전체 사진 화면 밝기 108% / 100% 복귀, 값 유지
* 기존 ZIP·나라별 백업/복원 기능 보유(웹 브라우저/실제 iPad 환경에서 검증 필요)
